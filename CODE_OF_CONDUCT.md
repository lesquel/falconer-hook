# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text at that link applies to every issue, pull request, discussion and other project
space.

## In short

- Be respectful and welcoming. Disagree about ideas, not people.
- Give and accept constructive feedback gracefully.
- No harassment, insults, sexualized language or imagery, or personal attacks.
- Do not publish other people's private information, such as addresses, IPs or hostnames,
  without their permission.

## Enforcement

The maintainer enforces this code of conduct through GitHub. Comments, commits, issues and pull
requests that break it may be edited, hidden or removed, and repeat or serious offenders may be
blocked from the project, following the Contributor Covenant's enforcement guidelines.

To report a problem, use GitHub's **Report content** option on the comment, issue or pull
request and choose to report it to the repository maintainers.
